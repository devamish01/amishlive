# Running the Project

## Prerequisites
- Node.js 16+ installed
- npm available in your terminal

## Install dependencies
```bash
npm install
```

## Start the development server
```bash
npm run dev
```

## Open in browser
Visit:
```text
http://localhost:5173
```

## Build for production
```bash
npm run build
```

## Preview production build locally
```bash
npm run preview
```
